# symbol-web

## Описание

`symbol-web` — веб-приложение на Go для преобразования печатного ASCII-текста в большие графические надписи. Пользователь вводит текст, выбирает один из трёх баннеров (`standard`, `shadow`, `thinkertoy`) и получает результат на той же странице.

В приложение также встроены AI-функции:

- подсказки продолжения текста через LLM;
- детерминированная рекомендация баннера без LLM;
- творческие варианты текста через LLM (бонусная функция);
- штатный mock-режим, которому не нужны API-ключ и сеть.

### Функционал

- генерация ASCII-арта из символов с кодами 32–126;
- поддержка переводов строк и последовательности `\n`;
- ограничение входного текста до 1000 символов;
- интерактивные подсказки с задержкой 300 мс;
- выбор рекомендованного баннера одним нажатием;
- выбор творческого варианта из модального окна;
- понятные HTML- и JSON-ошибки;
- 10-секундный таймаут внешнего LLM-запроса;
- модульные тесты генератора, AI-логики и HTTP-обработчиков.

### Технологии

- Go 1.22 и только стандартная библиотека;
- `net/http`, `html/template`, `encoding/json`;
- HTML5, CSS3 и JavaScript без фреймворков;
- Ollama API или OpenAI-совместимый Chat Completions API.

## Использование: как запустить

### Требования

- Go 1.22 или новее;
- для mock-режима больше ничего не требуется;
- для live-режима нужен запущенный Ollama либо доступный OpenAI-совместимый сервер и установленная на нём модель.

### Установка

```bash
git clone https://01.tomorrow-school.ai/git/ntleukha/symbol-web
cd symbol-web
go test ./...
```

### Настройка окружения

Пример переменных находится в `.env.example`. Приложение читает переменные непосредственно из окружения и не загружает `.env` автоматически.

Mock-режим включается, когда `LLM_BASE_URL` не задан:

```bash
go run cmd/server/main.go
```

Live-режим с локальным Ollama в Linux/macOS:

```bash
export LLM_BASE_URL="http://localhost:11434"
export LLM_MODEL="llama3"
go run cmd/server/main.go
```

Live-режим в PowerShell:

```powershell
$env:LLM_BASE_URL = "http://localhost:11434"
$env:LLM_MODEL = "llama3"
go run cmd/server/main.go
```

Для OpenAI-совместимого сервера укажите базовый URL вида `https://host/v1` и, если требуется, `LLM_API_KEY`. Имя модели всегда берётся из `LLM_MODEL` и не зашито в коде.

После запуска откройте [http://localhost:8080](http://localhost:8080), введите, например, `Hello`, выберите баннер и нажмите «Создать арт».

## Детали реализации

### Алгоритм ASCII-арта

Каждый баннер содержит 95 печатных ASCII-символов. Один символ занимает восемь строк, а соседние блоки разделены пустой строкой. Генератор:

1. проверяет текст и имя баннера;
2. загружает выбранный файл и проверяет его структуру;
3. вычисляет блок по формуле `(код символа - 32) × 9 + 1`;
4. объединяет одинаковые строки блоков слева направо;
5. отдельно сохраняет переводы строк исходного текста.

`standard` используется по умолчанию. Неизвестное имя баннера возвращает `400`, а отсутствующий файл допустимого баннера — `404`.

### AI-интеграция

Если `LLM_BASE_URL` пуст, методы LLM возвращают повторяемые mock-ответы. Это нормальный режим работы, а не обработка ошибки.

Если адрес задан, клиент отправляет запрос с моделью из `LLM_MODEL`:

- адрес без специального пути считается Ollama-сервером, к нему добавляется `/api/generate`;
- адрес, заканчивающийся на `/v1`, считается OpenAI-совместимым, к нему добавляется `/chat/completions`;
- полные пути `/api/generate` и `/chat/completions` также поддерживаются.

Сетевой сбой, таймаут или недоступность внешнего сервиса дают `503`. Некорректный ответ LLM даёт `500`; сервер при этом продолжает работу.

### HTTP API

#### `GET /`

Возвращает главную HTML-страницу.

#### `POST /symbol-art`

Принимает HTML-форму:

- `text` — непустой печатный ASCII-текст, максимум 1000 символов;
- `banner` — `standard`, `shadow` или `thinkertoy`.

Возвращает главную страницу с готовым ASCII-артом.

#### `POST /api/suggest`

Требует минимум три символа:

```json
{"text":"Happy Birth"}
```

Ответ содержит от трёх до пяти строк короче 50 символов:

```json
{"suggestions":["Happy Birth!","Happy Birth World","~ Happy Birth ~"]}
```

#### `POST /api/recommend-banner`

Работает только на правилах и никогда не вызывает сеть. Верхний регистр и текст до шести символов предпочитают `shadow`, текст длиннее 12 символов — `standard`, а насыщенный символами или короткий смешанный текст — `thinkertoy`.

```json
{"text":"WELCOME"}
```

Ответ содержит `recommended`, объяснение `reasoning` и две оценённые альтернативы.

#### `POST /api/variations`

Возвращает от трёх до пяти объектов с полями `text`, `description` и `suggested_banner`. В mock-режиме всегда возвращаются четыре варианта: деловой, выразительный, дружелюбный и декоративный.

### Архитектура фронтенда

- `templates/index.html` содержит форму и области для динамических результатов;
- `static/js/suggestions.js` выполняет debounce и показывает кликабельные подсказки;
- `static/js/recommendations.js` выбирает и подсвечивает рекомендацию;
- `static/js/variations.js` показывает идеи и переносит выбранную идею в форму;
- DOM формируется через `textContent`, поэтому текст LLM не интерпретируется как HTML.

## Пример работы

```text
$ go run cmd/server/main.go
symbol-web: сервер запущен на http://localhost:8080 (AI: mock)
```

1. Откройте веб-интерфейс.
2. Введите `Hello`.
3. Дождитесь подсказок или нажмите «AI Recommend Banner».
4. Выберите один из трёх баннеров.
5. Нажмите «Создать арт».
6. Результат появится под формой без перехода на другую страницу.
